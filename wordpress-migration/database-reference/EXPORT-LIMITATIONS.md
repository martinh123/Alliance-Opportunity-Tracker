# Export limitations

The original application administrator export is generated by:

`wordpress-migration/source/artifacts/api-server/src/routes/org-export.ts`

Its version-2 shape contains:

`users`, `partners`, `partnerResources`, `internalResources`, `opportunities`, `meddpiccEntries`, `meddpiccSectionMeta`, `companyResearch`, `reminders`, and `profiles`.

The Git-hosted file keeps that same shape, but it is sanitized for safe repository and Copilot access:

- All people, organizations, companies, emails, phone numbers, locations, notes, and research text are fictional.
- User `password_hash` values are explicit redaction markers, not usable credentials.
- Organization `mcp_key` is an explicit redaction marker.
- No production database rows are published.
- No API keys, session secrets, cookies, private keys, or credential-bearing notes are published.
- The file is intended for schema/relationship/import development, not restoration of the live application.

If a real backup is needed, keep it in a protected database backup location and do not commit it to GitHub.
